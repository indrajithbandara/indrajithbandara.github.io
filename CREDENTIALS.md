# Credential directory

`credentials.json` is the historical transcript dataset dated 2026-11-22. It is not a count of current certifications. The original transcript is not published. `credential-directory.json` is the derived public directory. Run `node tools/build-credentials.mjs` from the repository root to rebuild from the original dataset. Run `node tools/validate.mjs` to validate.

`credential-descriptions.json` contains privacy-filtered description excerpts (up to 500 characters) and explicit expiration dates from the supplied transcript. All 280 titles, issuers and issue dates were matched against the original 82-page PDF. No names, private identifiers, grade or academic credit details were included in this supplemental file. Skills are unavailable when the source does not explicitly enumerate them.

IDs derive from title, issuer, authorizing organization and issue date. The model uses null for unavailable dates, URLs, types, descriptions and synchronization time. Domains are inferred from title patterns and may overlap. The public wallet was manually observed on 25 November 2026, yielding 279 distinct Credly badge IDs and 7 external cards (not included). The validated public snapshot is in `credly-public-snapshot.json`. Merge uses issuer + title + issue date, or issuer + title uniqueness for cards displaying expiration rather than issue date. A documented OWASP symbol transcription correction reconciles one record. One historical transcript record has no corresponding public card. No title-only joins are performed. Source validity labels are preserved; “Issued” does not establish active or permanent status. No scheduled scraping is enabled.

To import a new manually observed public wallet snapshot, run `node tools/import-public-snapshot.mjs <public-card-json>` then `node tools/build-credentials.mjs` and `node tools/validate.mjs`. The importer validates URL hosts, badge IDs, count, date labels and duplicates before replacing the snapshot. Do not use private interfaces or credentials. A failed import retains the previous snapshot. The [Credly User Terms](https://info.credly.com/user-terms-of-service) prohibit automated access, so the scheduled workflow validates the published snapshot only; it does not retrieve Credly data automatically. A documented, authorized API integration is required for automated refresh.
